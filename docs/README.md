# Wine Recommendation System - Documentation

This directory contains additional documentation for the Wine Recommendation System.

## Contents

- **API Reference**: Detailed documentation of classes and functions
- **User Guide**: Step-by-step guides for using the system
- **Developer Guide**: Information for contributors and developers
- **Tutorials**: Practical examples and use cases

## Building Documentation

To build the full documentation (requires Sphinx):

```bash
pip install sphinx sphinx-rtd-theme
cd docs
make html
```

The documentation will be available in `docs/_build/html/index.html`
